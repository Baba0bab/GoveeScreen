# Security policy / Politique de sécurité

## Supported versions

Only the [latest release](https://github.com/Baba0bab/GoveeScreen/releases/latest) receives security fixes.

## Reporting a vulnerability

**Do not open a public issue.** Use GitHub's private reporting: [**Report a vulnerability**](https://github.com/Baba0bab/GoveeScreen/security/advisories/new) (*Security* tab of the repository). Include the affected version, a description, the impact and steps to reproduce. You will get an answer within 7 days; please allow time for a fix before any public disclosure.

Examples of relevant issues: screen content leaving the PC, data sent anywhere other than the lamp on the local network, a crafted network packet (for example a discovery reply) that crashes the app or makes it run code, files written outside the app's folders.

---

## Versions maintenues

Seule la [dernière version](https://github.com/Baba0bab/GoveeScreen/releases/latest) reçoit des correctifs de sécurité.

## Signaler une faille

**N'ouvrez pas d'issue publique.** Utilisez le signalement privé de GitHub : [**Report a vulnerability**](https://github.com/Baba0bab/GoveeScreen/security/advisories/new) (onglet *Security* du dépôt). Indiquez la version concernée, une description, l'impact et les étapes pour reproduire. Réponse sous 7 jours ; merci de laisser le temps de publier un correctif avant toute divulgation.

Exemples de problèmes concernés : contenu de l'écran qui quitte le PC, données envoyées ailleurs qu'à la lampe du réseau local, paquet réseau forgé (par exemple une réponse de découverte) qui fait planter l'application ou lui fait exécuter du code, fichiers écrits hors des dossiers de l'application.
